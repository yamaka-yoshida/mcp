はじめに

このマニュアルは、帳票レイアウト作業を Cursor（AI エージェント） と連携させるための仕組みを説明します。Scribus 1.7.x を GUI で編集するときも、headless で一括生成するときも、同じ約束事（座標・レイヤー・ファイル配置）に従います。

🔌

MCP（scribus）

Cursor から Scribus を直接操作。テキストフレーム・罫線・保存・PDF 書き出しなど約 125 ツール。

📋

Skills

エージェントへの作業手順書。座標系・レイヤー・やってはいけないことを自動参照。

🛠

Layout Kit

.sla のシフト・フィット・正規化・レイヤー照合を行う Python CLI。

3 層構成

帳票レイアウトの責務は 3 層に分かれています。プロジェクト固有の座標は MCP 本体に書かず、各層の正本に閉じ込めます。

MCP（scribus-mcp）の使い方

MCP は Cursor のチャットから Scribus を操作するための橋渡しです。既定は mode=auto で、開いている Scribus があれば interactive、なければ headless にフォールバックします。

Interactive の初回セットアップ

  1. Scribus 1.7.3 を起動する
  2. PowerShell で scribus-mcp --print-bridge-path を実行し、.spy ファイルのパスを確認
  3. Scribus メニュー「スクリプト → スクリプトを実行」で bridge を読み込む
  4. Cursor チャットで「運行指示書.sla を開いて」と依頼 → MCP が Scribus を操作

よく使う MCP ツール

ツール用途
open_document / save_document.sla の開閉・保存
set_active_layer / list_layersレイヤー切替（作成前に必須）
create_text_frame / set_text / set_fontテキスト配置
create_line / create_rectangle罫線・矩形
render_page_to_imageレイアウトの目視確認
export_pdfPDF 書き出し
注意 新規ドキュメントは UNIT_POINTS + PAPER_A4 で作成してください。mm 単位の newDocument だけだとページ幅が約 3 倍になる既知バグがあります。

Skills の使い方

Skills は Cursor エージェントがタスク開始時に自動参照する Markdown 形式の手順書です。帳票レイアウトでは 汎用 Skill と プロジェクト Skill の 2 段構成です。

エージェントへの依頼例

  • 「運行指示書.sla の表ヘッダー行の高さを 8mm にして」→ MCP + プロジェクト Skill がパスを解決
  • 「calibration を読んで、左に 2mm ずれている罫線を直して」→ Kit の shift 手順を参照
  • 「新しい帳票テンプレート用に calibration を init して」→ 汎用 Skill の新規手順を実行

新規プロジェクト用 Skill の作り方

  1. .cursor/skills/scribus-<プロジェクト名>-design/SKILL.md を作成
  2. 汎用 Skill への参照と、design/*.calibration.json のパスを記載
  3. 帳票固有のレイヤー使用状況・キャリブレーション値を表で整理

Layout Kit CLI

scribus-layout-kit は Scribus 外から .sla を操作する Python ツール群です。プロジェクトでは design/sla_tool.py ラッパー経由で --calibration を自動付与できます。

cd <プロジェクト>\design

python sla_tool.py info          # バウンディングボックス・余白矩形
python sla_tool.py layers        # レイヤー標準との照合
python sla_tool.py shift --dx-mm 35   # 全オブジェクトをシフト
python sla_tool.py fit --percent 98 --dry-run   # スケール倍率の確認
python sla_tool.py normalize --remove-headless-offset  # ページサイズ・ガイド修正
コマンド説明
init新規 *.calibration.json をテンプレートから作成
infoコンテンツ bbox と目標余白矩形を JSON 表示
layersレイヤー名・順序・印刷可否を標準と照合
shift位置キャリブレーション（mm 単位シフト）
fit余白内に uniform スケール（--dry-run 推奨）
normalizeA4 修正・ガイド設定・headless オフセット除去
引数の順序 サブコマンドの後に --calibration を付けます。例: info --calibration design\帳票.calibration.json。ラッパー sla_tool.py 使用時は省略可。

レイヤー標準（form-standard-v1）

帳票は下から上へ 5 レイヤーで分けます。シンプルな静的帳票は最小 3 層（背景・罫線・見出し）で十分です。

データAcroForm 位置参考
見出し固定ラベル・タイトル
罫線表枠・罫線
背景塗り矩形・背景色

オブジェクト種別 (kind)レイヤー例

line, grid, border_rect罫線表の外枠・区切り線

MCP でのレイヤー操作手順

  1. list_layers で現状確認
  2. 不足があれば create_layer
  3. オブジェクト作成前に set_active_layer
  4. 既存オブジェクトの移動は send_to_layer

作業フロー

座標キャリブレーション

作業座標と Scribus 内部座標の対応は *.calibration.json が正本です。

headless 生成時の +35mm ずれ Scribus headless 実行後、オブジェクトが左方向に約 35mm（≈100pt）ずれることがあります。目視確認後 sla_tool.py shift --dx-mm 35 で補正し、結果を calibration.json に記録してください。

Cursor への指示例

チャットにコピー＆ペーストして使える依頼文です。プロジェクト名・ファイル名は環境に合わせて置き換えてください。

OPEN 開く・保存・確認

sla を開く
運行指示書.sla を Scribus で開いて、現在のレイヤー一覧を表示して。
プレビュー
開いている .sla の 1 ページ目を render_page_to_image で画像化して、レイアウトを確認して。
保存
編集内容を save_document で保存して。
PDF 出力
現在のドキュメントを export_pdf で work フォルダに PDF 書き出しして。

EDIT レイアウト編集

罫線追加
レイヤー「罫線」をアクティブにして、作業原点から右端まで Y=50mm の水平線を 0.5pt で引いて。
ラベル追加
レイヤー「見出し」に「運転日」ラベルを (0, 20) mm、幅 18mm、IPAexGothic 9pt で置いて。
表ヘッダー
表のヘッダー行の高さを 8mm に変更して。列見出しは見出しレイヤーのまま。
背景色
セクション見出し帯を背景レイヤーで section_bg 色の矩形にして。
レイヤー移動
誤って見出しレイヤーに入った罫線を、send_to_layer で「罫線」に移して。

CAL キャリブレーション・CLI

bbox 確認
design フォルダで python sla_tool.py info を実行して、余白との関係を説明して。
ずれ補正
calibration.json を読んで、全体が左に 2mm ずれているので sla_tool.py shift --dx-mm 2 を実行して。
スケール確認
sla_tool.py fit --percent 95 --dry-run で余白フィットの倍率を確認して、結果を教えて。
レイヤー照合
python sla_tool.py layers を実行して、form-standard-v1 との差分を報告して。
headless 後処理
headless 生成後なので sla_tool.py normalize --remove-headless-offset を実行してから layers で確認して。

NEW 新規テンプレート

calibration 初期化
新帳票「納品書」用に sla_tool.py init で calibration を design に作成し、project_sla_tool.py.template からラッパーも用意して。
レイヤー準備
form-standard-v1 の 5 レイヤー（背景・罫線・見出し・データ・作業）を create_layer で用意して。作業レイヤーは印刷オフに。
A4 新規
UNIT_POINTS + PAPER_A4 で A4 縦・余白 14.111mm の新規ドキュメントを作って。mm だけの newDocument は使わないで。
Skill 追加
.cursor/skills/scribus-納品書-design/SKILL.md を scribus-unko-design を参考に作成して。

CHECK 検証・トラブル時

MCP 接続確認
scribus MCP で get_scribus_version と list_layers が動くか確認して。動かなければ bridge 手順を案内して。
座標の読み方
運行指示書.calibration.json の origin_page_mm を読んで、作業座標 (10, 5) mm のページ絶対座標を計算して。
ページ幅異常
ページ幅が A4 の 3 倍になっている。normalize とページ作成方法を確認して直して。

トラブルシューティング

症状原因・対処
MCP が Scribus に接続できない interactive 時は bridge .spy の読み込みを確認。headless 時は Scribus プロセスが残っていないか確認。
ページ幅が A4 の 3 倍になる newDocument を mm 単位だけで呼んでいる。pt + PAPER_A4 を使う。
sla_tool がエラー（invalid choice） --calibration はサブコマンドの後。ラッパー design/sla_tool.py を使う。
レイアウトが左にずれる headless オフセット。shift --dx-mm 35 または normalize --remove-headless-offset。
headless が遅い・タイムアウト 一括スクリプト（-g -py）を使う。GUI 編集は interactive MCP に切り替える。
オブジェクトが意図しないレイヤーに入る 作成前に set_active_layer。後から send_to_layer で移動。
やってはいけないこと headless 実行中に同じ .sla を GUI で開く · プロジェクト固有座標を MCP 本体にハードコード · mm だけの newDocument
