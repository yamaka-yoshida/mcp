# Excel 系 MCP

Excel 関連の MCP は **pip パッケージ** と **ExcelVBAproject ローカルスクリプト** の組み合わせです。

| MCP ID | 入手方法 |
|--------|----------|
| `ExceLLM` | `pip install excellm` |
| `ExcelMcp` | `pip install mcp-excel` |
| `excel-automation` | `C:\work\ExcelVBAproject\scripts\mcp\excel_mcp_server.py` |
| `vba-skills` | `C:\work\ExcelVBAproject\scripts\mcp\skills_mcp_server.py` |

## 将来の改善案

ExcelVBAproject の MCP スクリプトをこのリポジトリにコピーまたは submodule 化すれば、完全に単一リポジトリ配布が可能です。現状は ExcelVBAproject が正本です。
